# Глоссарий и источники

| Термин | Значение |
| --- | --- |
| Брокер (broker) | Сервер Kafka, хранящий партиции и обслуживающий клиентов |
| Топик (topic) | Именованный поток событий |
| Партиция (partition) | Упорядоченный журнал внутри топика; единица параллелизма |
| Offset | Номер события в партиции |
| Ключ (key) | Часть события, по которой выбирается партиция |
| Лидер, фолловер | Основная и копирующая реплики партиции |
| ISR | Реплики, синхронные с лидером |
| Consumer group | Группа консьюмеров, делящих партиции топика |
| Лаг (lag) | Отставание группы от конца журнала |
| Retention | Срок или объём хранения событий |
| Compaction | Сжатие журнала: остаётся последнее значение для ключа |
| Tombstone | Событие с ключом и пустым значением, удаляющее ключ при сжатии |
| KRaft | Встроенный протокол метаданных и выбора контроллера, заменивший ZooKeeper |
| Идемпотентность | Повторная отправка не создаёт дублей |
| Kafka Connect | Инструмент переноса данных между Kafka и внешними системами |
| Kafka Streams | Библиотека потоковой обработки данных из Kafka |
| Сериализация | Превращение данных в байты для хранения и передачи; обратное превращение — десериализация |
| Avro | Компактный бинарный формат со схемой, записанной в JSON |
| Schema Registry | Отдельный сервис (не часть Apache Kafka), хранящий схемы и номера версий |
| Subject | Имя, под которым в реестре хранится история схемы (обычно <топик>-value) |
| Совместимость (compatibility) | Правило, по которому реестр принимает новую версию схемы: BACKWARD, FORWARD, FULL, NONE |

### Источники

**Статус проверки.** Флаги и параметры консольных утилит и конфигураций сверены с исходными файлами Kafka 4.3 в репозитории (server.properties, ConsoleProducer, GetOffsetShell, StorageTool, StreamsConfig и др.) и с официальным примером Docker Compose. Код Node.js уроков 7, 8, 9 (шаг 5) и 12 запускался на имитации кластера и реестра; синтаксис Compose проверен командой `docker compose config`, `pom.xml` — на корректность XML, Java-код — на синтаксис. **На настоящем брокере не запускалось:** кластер из урока 6 (ручной и в Docker), Maven-сборка урока 12, Kafka Connect, Kafka Streams, транзакции и настоящий Schema Registry (в среде автора был закрыт доступ к дистрибутивам Kafka, Maven Central и Docker Hub). Поэтому перед занятием пройдите уроки 2, 6, 8 и 12 на чистой машине и поправьте то, что разойдётся.

- [Apache Kafka Quickstart](https://kafka.apache.org/quickstart): установка, топики, консольные клиенты, Connect.
- [Apache Kafka Introduction](https://kafka.apache.org/intro): основные понятия и программные интерфейсы.
- [KRaft (раздел Operations, 4.3)](https://kafka.apache.org/43/operations/kraft/): роли узлов, кворум контроллеров, форматирование.
- [Kafka Streams Quick Start (4.3)](https://kafka.apache.org/43/streams/quickstart/): демонстрационное приложение WordCount.
- [Upgrading to 4.2 (KIP-1147 и новые имена флагов)](https://kafka.apache.org/42/getting-started/upgrade/).
- [Документация Kafka](https://kafka.apache.org/documentation): конфигурации, дизайн, безопасность, эксплуатация.
- [Confluent Schema Registry](https://docs.confluent.io/platform/current/schema-registry/index.html) и [Avro](https://avro.apache.org/docs/): реестр схем, режимы совместимости, REST-интерфейс (урок 8).
