# Методичка по Apache Kafka (версия для Node.js)

Курс из 13 уроков: от «что такое Kafka» до кластера, форматов данных, гарантий доставки и потоковой обработки. В каждой папке `lesson-NN` лежит `README.md` с текстом урока, а если нужен код, то и папка `code/`.

## Структура

```
kafka-course/
├── index.html          начните отсюда: оглавление курса
├── README.md
├── package.json        зависимости для примеров на Node.js
├── GLOSSARY.md         глоссарий
├── SOURCES.md          источники и статус проверки
├── lesson-01/ … lesson-13/
│   ├── lesson.html     урок в оформлении (откройте в браузере)
│   ├── README.md       тот же текст в Markdown
│   └── code/           примеры кода (только где нужны)
└── project/
    └── README.md       итоговый проект
```

## Как пользоваться

1. Проходите уроки по порядку, один урок за 90–120 минут.
2. Для примеров на Node.js нужен Node.js 18+ (проверено на 22). В корне выполните `npm install`.
3. Запускайте примеры из папки `code/` нужного урока, например `node lesson-07/code/producer.js`. Адрес брокера задаётся переменной `BOOTSTRAP` (по умолчанию `localhost:9092`).
4. Для уроков 8 и 9 нужен кластер из Docker Compose (`lesson-06/code/docker-compose.yml`).

## Среда разработки

Работать можно в любой IDE или редакторе (VS Code, WebStorm, IntelliJ IDEA, Sublime Text и другие). Специальные плагины не нужны: достаточно Node.js, терминала (встроенного в IDE или обычного) и Docker для уроков с кластером. Откройте папку `kafka-course` как проект и запускайте примеры из терминала.

Что проверено, а что нет, описано в [SOURCES.md](SOURCES.md).
